# Four-Video Weekly Production Runbook

## Monday — Research and script lock
1. Select four admitted queries from `video-queue.json`.
2. Recheck source dates and article records.
3. Draft all four scripts from `script-template.md`.
4. Run human factual review and lock the final transcript text.

## Tuesday — Rights and footage assembly
1. Build a visual beat sheet for each script.
2. Admit clips into `asset-rights-manifest.json` before editing.
3. Reject footage with unclear commercial rights.
4. Create proxy bins by creature, zone, source and depth.

## Wednesday — Voice and rough cuts
1. Generate narration using the locked narrator profile.
2. Listen to the entire file; repair pronunciation before edit.
3. Assemble A-roll narration, primary footage and diagrams.

## Thursday — Finish and package
1. Mix audio and apply the stable visual system.
2. Add captions, source callouts, chapters and end card.
3. Complete thumbnail and metadata draft.
4. Export masters and run the synchronization checklist.

## Friday — Publish and pair
1. Upload the video.
2. Add the canonical article URL to the description.
3. Enter final public metadata in the canonical question record.
4. Rebuild the site so the player and VideoObject schema activate.
5. Verify article-to-video and video-to-article links.

## Capacity fallback
If four videos cannot pass review, publish two complete videos. Do not push four partially sourced or rights-unclear videos to preserve a quota.

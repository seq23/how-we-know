# Article ↔ Video Synchronization Checklist

- [ ] Exact query wording is preserved in the article H1 and video title.
- [ ] The first description line agrees with the canonical direct answer.
- [ ] The final script was reviewed after all factual edits.
- [ ] The transcript matches the final narration, not an earlier draft.
- [ ] Chapters match the uploaded video's final timing.
- [ ] Every visual asset has an admitted rights record.
- [ ] Every required credit appears in the description or end credits.
- [ ] The video description links to the canonical article.
- [ ] The canonical question record contains the real public video ID.
- [ ] Upload date, duration and thumbnail URL are real values.
- [ ] The rebuilt article visibly embeds the video.
- [ ] VideoObject markup is present only after the visible embed exists.

# Editing Template Specification

## Approved editors
- Primary: DaVinci Resolve free edition when the workstation meets current requirements.
- Low-friction fallback: CapCut Desktop, with project settings documented at creation.

## Master timeline
- 3840×2160 or 1920×1080, 30 fps.
- Audio: 48 kHz.
- Target runtime: 8–12 minutes.
- Track V1: primary footage.
- Track V2: diagrams, labels, source callouts and maps.
- Track V3: texture or secondary cutaways.
- Track A1: narrator.
- Track A2: music.
- Track A3: restrained sound design.

## Visual cadence
Change the visual idea every 5–12 seconds without using meaningless motion. Hold longer when a diagram or rare expedition shot needs inspection.

## Source callout
When a quantitative or surprising claim first appears, show the source organization in a small lower-third. Full URLs belong in the article and production notes, not as unreadable screen text.

## Audio targets
- Narrator is always intelligible over music.
- Remove long silences and obvious synthesis artifacts.
- Use one loudness preset across the channel; record the actual measured target after the first test export.

## Export naming
`DSR_###_<question-slug>_MASTER_v01.mp4`

No template project file is claimed in this artifact. The first editor project must be created locally after the editor and workstation are selected.

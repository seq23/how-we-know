# Production System

This directory contains the twenty-video launch system: final editorial baselines, human-pass controls, Kokoro TTS, original motion assets, music beds, thumbnails, FFmpeg rendering, YouTube scheduling, provider receipts, and site synchronization.

Final render is deliberately blocked until every selected script has a valid human-approval hash. YouTube mutation is dry-run-first and never fabricates provider IDs.

See `../docs/runbooks/TWENTY_VIDEO_ACTIVATION.md`.

# Narrator selection

**Selected lane:** Kokoro-82M, `af_heart`, speed 0.98.

This is the stable production configuration. The current execution environment could not install Kokoro because its package mirror did not expose the package and only Python 3.13 was available. No claim is made that final narration files were generated here.

The repository includes a Colab/local installer and synthesis script. FFmpeg `flite` is permitted only for automated smoke tests; it is not an approved public narrator.

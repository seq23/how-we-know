# Runtime dependencies for the scheduled loop workflows.
#
# Added 2026-08-31 after the Monday draft stage failed with
# `ModuleNotFoundError: No module named 'PIL'`. The workflows had no pip install
# step at all, so a validator crashed on import and the circuit breaker read that
# crash as a validation failure. Publishing was correctly halted - but for the
# wrong reason, and a breaker that trips on missing packages is one people learn
# to ignore. Pin these so the loop only ever fails for real reasons.
pillow==12.3.0
numpy==2.5.2

# NOTHING IS NEEDED HERE FOR CLOUDFLARE R2, and that is deliberate. The cloud
# upload lane reaches R2 through the `wrangler` CLI (installed by npm in
# .github/workflows/loop-upload-cloud.yml), not through boto3 and the S3 API.
# boto3 would mean minting a SECOND credential — an R2 S3 API token with its own
# access key and secret — where the owner already has a working Cloudflare API
# token that wrangler authenticates with. One credential that exists beats four
# that have to be created, stored and rotated.
